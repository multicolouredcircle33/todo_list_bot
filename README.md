# 📌 Telegram To-Do & Reminder Bot

A simple and interactive Telegram bot that helps you manage your tasks and reminders. Access it directly via Telegram—no installation required.

---

## 🚀 Features

- ✅ Add new tasks with descriptions and scheduled times  
- 📋 View all tasks  
- ✔️ Mark tasks as completed  
- 🗑️ Delete tasks  
- ⏰ Receive automatic reminders  
- ❌ Cancel task creation anytime  

---

## 🤖 Bot Commands

| Command     | Description                      |
|------------|----------------------------------|
| /start     | Start the bot and get a welcome message |
| /add       | Add a new task                   |
| /view      | View all tasks                   |
| /complete  | Mark a task as completed         |
| /delete    | Delete a task                    |
| /cancel    | Cancel the current operation     |
| /help      | Show all commands                |

---

## 🌐 Access the Bot

The bot is deployed and running on Render. You can start using it immediately by clicking the link below:

[Open Bot on Telegram](https://t.me/my_handy_todolist_bot)

---

## 🧠 How It Works

1. Interact with the bot directly in Telegram  
2. Add tasks with descriptions and scheduled times  
3. Tasks are stored on the server and reminders are automatically sent  
4. You can view, complete, or delete tasks at any time
